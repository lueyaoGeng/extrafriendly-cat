# Extrafriendly Cat 插件

这是 Extrafriendly Cat 客户端的功能模块，沿用 OpenPets SDK v3 的窗口、原生气泡、菜单、持久化、定时器和网络权限机制。首次启动会打开“我的猫”；之后可右键猫猫，选择“我的猫 · 设置”。

聊天、每日专辑、小笑话、天气、喂食、铲屎、互动声音、轻提醒和 API 接入/额度提醒都可以独立开启或关闭。声音和日常主动提醒默认关闭，API 提醒默认开启。动画和自定义外观由桌面客户端的偏好设置拥有，面板只通过限定消息请求调整，不复制这两项持久化状态。

猫始终认为自己是用户养的猫，温柔支持用户。饱腹度、清洁度只在客户端连续运行时缓慢变化，每小时分别减少 4 和 3；数值范围 0–100。关闭功能、退出、睡眠、锁屏期间不累积变化。没有好感度、惩罚、疾病、死亡或事后补扣。

日常照料直接通过原生菜单、气泡按钮或面板使用。聊天输入也支持明确的快捷话语“喂食”“铲屎”“今天听什么”“讲个笑话”“天气”。这些操作仍检查对应开关。关闭聊天或切换服务会清空当前内存对话并丢弃在途回复。对话不写入插件存储。

免费聊天服务当前明确显示“待上线”，不会伪装成在线服务。个人 API 使用已有的客户端配置入口，只有用户主动选择个人 API 才会调用它。免费服务错误和限额不会触发个人 API。发布免费服务时，在 `gateway-config.js` 设置 HTTPS 来源，并在 manifest 的 `network.hosts` 增加它的精确主机名，再重新构建。客户端生成并保存一个随机设备 UUID，发送到网关作粗粒度额度识别；这不是防伪设备身份。

免费聊天每条最多 2048 个 UTF-8 字节，中文约 680 字；超长输入会在调用前说明。客户端自动缩短较旧的历史，并按 8 KiB 历史和 16 KiB 请求体预算裁剪，保留本次用户消息。服务器负责可信猫人格，免费请求不发送客户端系统提示。

首次安装或 0.1 升级展示一次「聊天与 API」，可跳过。`api-guide.js` 提供国内平台的官方入口、可选中复制的地址和免费模型名，不接收任意链接。`quota-notice.js` 校验网关返回的剩余次数、范围和重置时间，排除过期/异常数据；低额度和耗尽各提醒一次并跨重启保存。分钟限制只提示稍等，提醒开关不会更换聊天服务。提示不进入模型对话历史。免费额度尚未上线时没有虚构的剩余数字。

天气只查询用户选择的城市。地理编码、实时天气和明日预报来自 Open-Meteo；缓存注明查询时间，超过一小时标为旧数据。每天的专辑保存在同一份状态里，当天重启不会改变，下一次选择不会连续重复。评分保留原始媒体、量表、来源 URL、乐评日期与核对日期；音乐平台按钮是明确标示的搜索链接。完整的专辑来源见 `ALBUM_SOURCES.md`。

轻提醒只在客户端运行时触发：09:30 推荐当天专辑；饱腹度或清洁度低于 35 时，照料提示至少间隔四小时。不追补错过的时间。

## 开发与检查

在仓库根目录运行：

```powershell
node plugins/official/extrafriendly.cat/build.mjs
node plugins/official/extrafriendly.cat/test.js
```

`index.js` 是提交到包内的自包含浏览器模块。插件宿主用 data URL 加载入口，因此不可直接把含有相对 import 的源码作为运行入口。`build.mjs` 复用桌面 Vite 工具链已有的 esbuild 生成入口，不增加第二套插件加载器。编辑 `companion.js`、纯逻辑或专辑数据后必须重新构建。桌面构建脚本已接入此步骤。

面板由 `panel/template.html`、`panel/panel.js`、`panel/style.css` 构建为单个 `panel/index.html`。插件安装快照只复制 manifest 声明的页面与资源，不能依赖未声明的独立 JS/CSS。生成源页面带内容哈希；安装时由宿主替换为统一面板 CSP，并用请求过滤器限制文件访问。图片继续使用 manifest 声明的 SVG。

照料计时使用宿主拥有的单个 `schedule.once` 槽位，每分钟重新安排并在停止时取消。SDK 的 `schedule.every` 要求至少十分钟，不能用于此处。原生静态气泡遵守单行 140 字上限，详细专辑和天气保留在面板；AI 气泡遵守动态文本 2000 字上限。

## 权限

照料按分钟检查猫是否显示；隐藏时冻结数值。聊天框中的喂食、铲屎、专辑、笑话、天气指令走本地入口，关闭功能会给简短说明。指定城市的天气先列出候选城市，不猜位置；这些指令不会消耗聊天 API。冷笑话不连续重复。

需要气泡与动态文本、猫猫反应、点击事件、调度、插件存储、菜单命令、可选声音、独立面板、用户配置的 AI、HTTPS 读取/写入和打开浏览器。仅声明 Open-Meteo 的两个精确域名；免费网关上线后需要加入其域名。没有麦克风、剪贴板、屏幕内容、任意文件访问或任意外网权限。面板不直接访问网络，也不执行用户导入外观中的代码。
